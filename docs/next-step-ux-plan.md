# 下一步体验修改计划

这份文档用于持续记录 FigureLearning / 知识酷 的下一步体验修改项。

使用方式：

- 先把你发现的问题、想优化的交互、页面不顺手的地方追加到“改动清单”。
- 每条尽量写清楚“当前问题”“目标体验”“建议动作”。
- 暂时想不清实现方案也没关系，可以先只记录问题和期望。
- 后续我可以继续基于这份文档，逐项帮你补成更完整的执行计划。

## 当前目标

- 让用户更清楚自己“现在在哪个工作区、选中了什么、下一步该做什么”。
- 优先优化真实主流程，不堆装饰性入口。
- 所有体验修改都尽量对应到真实页面、真实状态、真实 API 或真实保存动作。

## 修改原则

- 优先级先看主流程影响，再看视觉细节。
- 一次只解决少量高价值问题，避免同时大改全部页面。
- 能复用现有后端和已有工作区能力的，尽量不要重造。
- 未接入真实逻辑的入口，不作为体验优化目标中的“可用功能”。

#### 6. 链接收集提取稳定性

- 状态：待补充
